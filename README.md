### 👨‍💻 Professional Summary

I am a **Full-Stack Software Engineer** and **Cloud Infrastructure Practitioner** based in Indonesia 🇮🇩, with a proven track record of architecting, deploying, and maintaining production-grade web systems. My work bridges robust backend engineering, reactive web interfaces, and automated cloud operations.

- 💼 **What I Do:** Build scalable REST APIs, reliable database models, clean frontends, and automated CI/CD deployment pipelines.
- 🏗️ **Core Specialization:** Modern web architectures using **TypeScript**, **Node.js**, **Express 5**, **Prisma ORM**, **PostgreSQL**, and containerized workflows with **Docker** & **GitHub Container Registry (GHCR)**.
- 🚀 **Current Deployments:** Managing live, high-traffic systems across **F&B Cloud POS & Accounting**, **Logistics & Fleet Dispatch**, and **Enterprise Sales Management**.
- ⚡ **Engineering Mindset:** Prioritizing sub-second latency, zero-downtime rolling updates, resource-optimized multi-stage Docker builds, and automated DevOps pipelines.
